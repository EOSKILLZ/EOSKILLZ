## Ache

**Chat, code, automate. One Ache account.**

Ache is a hosted AI workspace for chat, research, code, and automation. Under it: an OpenAI- and Anthropic-compatible API, a terminal agent, a desktop app, and Bots — all sharing one account and one model catalog.

I build the whole system — React front end, Express/SQLite API, Tauri/Rust desktop app, CLI, auth, billing, model routing, and the agent loop.

## LocalOwl

**AI code review that never leaves your machine.**

A self-hosted GitHub bot. Open a pull request and LocalOwl pulls the diff, runs it through a local LLM, and posts a structured review: bugs, security, performance, code quality, and a clear approve/deny verdict. No cloud, no subscription, no code leaving the machine.

`Python` · `LM Studio` · `GitHub API` · `Docker` · `MIT`
